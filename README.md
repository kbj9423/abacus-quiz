# 주판 덧셈 대결

주판으로 세로 덧셈 문제를 푸는 웹페이지입니다. 휴대폰으로 보는 것을 기준으로 만들었습니다.

- 사이트: https://kbj9423.github.io/abacus-quiz/

## 난이도 (한국주산협회 주산 검정기준 참고, 덧셈만)

- 쉬움: 한 자리 4줄. 더하는 세 번이 모두 5의 짝, 10의 보수, 5와 10 섞임 중 하나가 되는 문제만 나옵니다.
- 중간: 한 자리 6줄, 또는 두 자리 4줄이 섞여 나옵니다.
- 어려움: 두 자리 5줄.

## 혼자하기

난이도를 골라 5문제를 풀고, 맞힌 수와 걸린 시간을 봅니다. 기록에는 들어가지 않습니다.

## 같이하기 (1:1)

- 방을 만들 때 난이도를 고르고, 네 자리 방 코드를 친구에게 알려 줍니다.
- 같은 문제가 동시에 나오고, 둘 다 답을 낼 때까지 기다립니다. 한 문제에 30초이고, 시간을 넘기면 틀린 것으로 칩니다.
- 둘 다 맞히면 더 빨리 푼 사람, 한 사람만 맞히면 맞힌 사람이 이깁니다. 둘 다 틀리면 무승부로 세지 않습니다.
- 3번 먼저 이기면 최종 승리입니다.
- 한 문제가 끝날 때마다 판수·승리·패배·승률이 이 기기(브라우저)에 저장되어 첫 화면에 보입니다. 상대가 나가면 대결이 끝나고, 풀던 문제는 기록하지 않습니다.
